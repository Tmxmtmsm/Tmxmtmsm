## لعبة الثعبان (Snake)

طريقة التشغيل:
- افتح الملف `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا بسيطًا.

تشغيل خادم محلي (بايثون):

```bash
python3 -m http.server 8000 --directory /workspace
```

ثم افتح الرابط: `http://localhost:8000/index.html`

طريقة اللعب:
- الأسهم للتحكم باتجاه الثعبان.
- المسافة لإيقاف/استئناف.
- زر "إعادة" لإعادة اللعبة.

المحتوى:
- `index.html`: الصفحة الرئيسية وعناصر الواجهة.
- `styles.css`: تنسيقات الواجهة.
- `game.js`: منطق اللعبة والرسم.
